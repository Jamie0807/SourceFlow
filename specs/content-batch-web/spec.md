# Web 工作台首屏需求规格

状态：已确认，作为 T017 的首屏子集实现范围；完整 T017 仍未完成
版本：0.1
日期：2026-09-28
所属产品：SourceFlow

## 1. 目标

把 `apps/web` 从占位页推进为可运行、可演示的 Web/桌面共用首屏：用户可以在登录演示页完成表单校验并进入内容经营工作台，看到批次概览、待处理任务和快速入口。

本阶段只交付前端信息架构与交互骨架，不伪装真实登录成功，也不接入尚未完成的 Workspace、Source、ContentBatch API。

## 2. 用户流程

```text
打开 Web
→ 登录演示页
→ 输入合法邮箱和不少于 8 位密码
→ 进入工作台首页
→ 查看数据概览、最近批次和待处理任务
→ 点击“新建内容批次”看到下一阶段入口提示
```

## 3. 功能范围

### FR-WEB-001 登录演示页

- 页面使用语义化表单、邮箱标签、密码标签和提交按钮。
- 邮箱格式错误时显示中文错误提示。
- 密码少于 8 位时显示中文错误提示。
- 合法提交后进入工作台首页；页面明确显示“演示模式”状态，不调用真实 API。
- 页面支持键盘操作，焦点状态可见。

### FR-WEB-002 工作台首页

- 提供侧边导航：总览、内容批次、资产库、数据复盘。
- 显示当前工作区、用户身份和“演示模式”标识。
- 显示本周已发布、待审核、内容资产和平均互动率四项概览。
- 显示最近内容批次及 queued、processing、succeeded、failed 状态。
- 显示待处理任务和“新建内容批次”快速入口。
- 导航和按钮在没有真实 API 时保持可点击或给出明确的未开放提示，不出现无响应交互。

### FR-WEB-003 响应式布局

- 1280px 以上使用左侧导航和双栏工作区。
- 768px 到 1279px 收窄侧边栏并保持卡片可读。
- 360px 到 767px 使用顶部工作区栏、可横向滚动导航和单列卡片。
- 不依赖颜色单独表达状态；状态同时有文字和视觉标识。

## 4. 非目标

- 不实现真实注册、登录、Refresh Token 和 API Client。
- 不实现上传、AI 生成、编辑、审核和导出业务。
- 不引入设计系统或重量级图标库。
- 不修改 API、Prisma 和现有认证逻辑。

## 5. 验收标准

- React Testing Library 覆盖登录校验、合法登录转场、工作台关键内容和状态标签。
- `pnpm test:component -- --run` 通过。
- `pnpm build:web` 通过。
- 通过 360px、1280px、1440px 的浏览器截图或人工检查确认布局无横向溢出。
- `pnpm lint`、`pnpm format:check`、`pnpm spellcheck`、`pnpm typecheck` 通过。
