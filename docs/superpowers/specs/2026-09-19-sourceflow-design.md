# SourceFlow 产品设计决策记录

日期：2026-09-19
状态：用户已确认，可进入文档落地

## 已确认方向

SourceFlow 采用“创作者优先的 AI 内容复用工作台”路线。第一目标用户是播客、课程、知识类创作者、个人品牌和 1—10 人内容团队。

## 核心闭环

`长视频/音频/文章 → AI 理解 → 多形态复用 → 平台适配 → 审核 → 发布 → 数据复盘 → 下一批内容`

## 端形态

- 桌面端与 Web 端共用大屏信息架构，服务内容生产、批量编辑和数据运营。
- 手机与 Pad 共用小屏响应式信息架构，服务审核、灵感、轻编辑、异常处理和数据查看。

## MVP 边界

- 必须做内容源、转写、关键片段、AI 复用、平台适配、审核、排期、发布降级、基础复盘和轻量线索。
- 暂不做完整专业视频剪辑、全量客服中心、完整 CRM、白标和私有化。

## 商业模式

Free、Creator、Pro、Team、Agency 五档；订阅为主，AI 处理额度作为成本护栏，账号/品牌/成员是升级杠杆。

## 设计取舍

相比直接做 Buffer/Metricool 类全能后台，本方案优先验证“内容复用是否能让用户持续回来并愿意付费”。相比只做 OpusClip 类剪辑工具，本方案把发布、数据和转化纳入同一批次，形成长期资产。
