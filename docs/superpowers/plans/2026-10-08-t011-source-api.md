# T011 Content Source API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` or `executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for progress.

**Goal:** 为 MP4、MP3、WAV、TXT Source 提供租户安全的预签名上传、异步服务端校验、单阶段处理、查询和取消。

**Architecture:** API 创建 Source 与 TaskRun，通过 StoragePort 签发对象级短时 PUT URL，并通过 BullMQ publisher 发布任务。Worker 使用 workspace-scoped Source store、MinIO 对象流和媒体解析器完成 `source.validate`；校验成功后才开放单阶段转写/分析。Worker 同步更新 Source 和 TaskRun 状态，所有资源访问使用 membership guard 验证的 workspaceId。

**Tech Stack:** TypeScript strict、NestJS/Fastify、Prisma/PostgreSQL、S3 SDK v3、BullMQ/ioredis、`music-metadata`、`mp4box`、Vitest、Playwright、pnpm。

## Global Constraints

- 仅支持 MP4、MP3、WAV、TXT；单文件 `0 < sizeBytes ≤ 1,073,741,824`；音视频时长 `0 < durationSeconds ≤ 3,600`。
- 所有 Source/TaskRun 查询和写入必须附带可信 `workspaceId`；Source 写操作仅 owner/editor。
- 预签名上传使用 900 秒 TTL，签入 SHA-256；不得日志输出签名 URL、密钥或媒体正文。
- 任务使用确定性 idempotency key 和 BullMQ jobId；长任务不得阻塞 HTTP。
- 每个行为先写 Vitest 失败测试并确认按预期失败，再实现最小逻辑并复跑目标/回归测试。
- Prisma 变更仅添加向后兼容 migration；不得重写既有迁移或重置数据库。
- 默认测试使用 Fake Queue/Storage；MinIO 测试仅在显式 `MINIO_TEST_*` 环境变量齐全时执行。
- 不自动提交、push、合并或删除 Worktree；用户明确要求提交时使用 `pnpm commit`。

## Task 2: Storage 预签名 PUT 与 HeadObject checksum

**Files:** `apps/api/src/storage/storage.port.ts`, `minio-storage.adapter.ts`, 两个 Storage 测试文件、`apps/api/package.json` 和 lockfile。

**公共接口：**

```ts
export type PresignedPutResult = Readonly<{
  url: string;
  headers: Readonly<Record<string, string>>;
  expiresAt: Date;
}>;

export type StorageObjectMetadata = Readonly<{
  contentLength?: number;
  contentType?: string;
  checksumSha256?: string;
}>;

export interface StoragePort {
  putObject(input: StoragePutObjectInput): Promise<void>;
  getObject(input: StorageObjectReference): Promise<StoredObject>;
  deleteObject(input: StorageObjectReference): Promise<void>;
  createPresignedPut(
    input: StorageObjectReference & {
      contentType: string;
      contentLength: number;
      checksumSha256: string;
      expiresInSeconds: number;
    },
  ): Promise<PresignedPutResult>;
  headObject(input: StorageObjectReference): Promise<StorageObjectMetadata>;
}
```
