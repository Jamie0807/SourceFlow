# SourceFlow 手机 / Pad 端 PRD

手机和 Pad 使用同一套小屏信息架构。手机强调快速处理，Pad 在横屏时增加列表与详情双栏。视频复杂剪辑、批量平台配置和深度数据分析回到大屏完成。

## 1. 小屏端定位

适合在移动场景完成：

- 捕捉灵感和上传素材。
- 查看待办和审批内容。
- 快速改标题、文案、CTA 和标签。
- 查看发布结果和异常。
- 浏览核心数据和采纳复盘建议。

不适合在手机完成：

- 多轨视频剪辑。
- 50 条以上资产的批量编辑。
- 复杂权限和账单配置。
- 跨品牌的深度报表设计。

## 2. 断点与导航

- 手机竖屏：360—767 px，单列布局。
- Pad 竖屏：768—1023 px，单列或窄双栏。
- Pad 横屏：1024 px 以上，列表 + 详情双栏。
- 底部导航：工作台、内容、日历、数据、我的。
- 全局右上角：通知和快速上传。

## 3. 页面规格

### MP-01 移动工作台

模块顺序：

1. 工作区和通知。
2. 今日待办横向卡片。
3. 快速操作：拍摄/上传、语音灵感、从复盘生成。
4. 最近内容批次列表。
5. 一周数据摘要。

卡片支持左滑快捷操作：审核、排期、归档。

### MP-02 内容列表与详情

内容列表只保留标题、状态、平台、更新时间和负责人。点击进入详情页，顶部显示状态和平台，底部固定操作栏：编辑、审核、排期、更多。

### MP-03 轻量编辑

编辑页采用分段表单：

- 标题。
- 正文/脚本。
- 标签。
- CTA。
- 平台预览。

AI 操作放在键盘上方的横向工具条：缩短、改口语、换开头、补 CTA、引用来源。生成前显示额度消耗；生成后支持替换当前段落，不跳离页面。

### MP-04 审核中心

以“待我审核”为默认筛选。支持上下滑动切换资产，底部固定“退回”和“批准”。退回必须选择或输入原因。评论定位到文字段落，不要求手机端做复杂时间码标注。

### MP-05 移动日历

默认显示未来 7 天的时间线列表。Pad 横屏可切换周日历。点击卡片可改时间、平台和状态；拖拽排期只在 Pad 横屏开启，手机用“更改时间”弹窗。

### MP-06 数据与复盘

只显示四个核心指标和三张卡片：表现最好、需要重做、建议复用。支持按平台切换和时间范围切换。复杂图表在手机上改为可横向滚动的简图，并提供“查看详情”跳转大屏 Web。

### MP-07 快速灵感

支持语音输入、文字输入、拍照上传和从剪贴板读取链接。保存后可选择“稍后生成”，自动进入灵感箱。语音转写必须显示待确认状态，不得静默替换用户原话。

### MP-08 通知与异常

通知分为：审核、发布成功、发布失败、授权过期、额度不足。通知详情给出单一主操作，例如“重新授权”“重试发布”“导出发布包”。

## 4. Pad 适配

Pad 横屏使用：

- 左侧 320 px 列表。
- 中间主内容区。
- 右侧 280 px 操作/AI 抽屉，可按需显示。

Pad 竖屏和手机共用单列详情页。键盘连接时复用大屏端快捷键的基础集合。

## 5. 移动端权限与安全

- 默认不在通知预览中显示完整线索联系方式。
- 线索导出、删除源内容、断开账号需要系统级二次确认。
- 支持生物识别解锁已登录工作区。
- 离线时允许查看最近缓存的批次和草稿；发布和 AI 生成必须在线。

## 6. 小屏端验收

- 360 px 宽度下核心页面无横向溢出。
- 用户可以在 60 秒内完成一次标题修改和审核。
- 发布失败通知能在 2 次点击内到达重试或导出动作。
- Pad 横屏可以同时浏览列表和详情，手机不依赖悬浮 hover。
