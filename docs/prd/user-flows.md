# SourceFlow 核心用户流程

## 1. 首次创建内容批次

```mermaid
flowchart LR
  A[创建工作区] --> B[连接平台账号]
  B --> C[上传视频/音频/文章]
  C --> D{处理成功?}
  D -- 否 --> E[显示原因并重试]
  D -- 是 --> F[查看转写/章节/候选片段]
  F --> G[选择平台和内容类型]
  G --> H[设置语气/受众/CTA]
  H --> I[预估额度]
  I --> J[生成内容批次]
  J --> K[审核与编辑]
  K --> L[排期/导出/发布]
```

### 关键异常

- 文件格式不支持：不进入 AI 队列，给出支持格式和转换建议。
- 转写失败：保留原文件，允许更换语言/重试。
- 额度不足：允许减少生成数量，或跳转购买额度。
- 平台未授权：允许先生成，发布时提醒连接账号。

## 2. 审核与发布

```mermaid
stateDiagram-v2
  [*] --> 草稿
  草稿 --> 待审核: 提交审核
  待审核 --> 已批准: 审核通过
  待审核 --> 需修改: 审核退回
  需修改 --> 待审核: 修改后再次提交
  已批准 --> 已排期: 选择时间
  已批准 --> 待发布: 立即发布
  已排期 --> 已发布: 平台成功
  已排期 --> 发布失败: 平台返回错误
  发布失败 --> 已排期: 重试
  发布失败 --> 导出发布包: 平台不支持或持续失败
```

## 3. 数据复盘到下一批内容

```mermaid
flowchart LR
  A[同步24小时以上数据] --> B[按平台/主题/内容类型聚合]
  B --> C[识别高表现和低表现模式]
  C --> D[生成可解释复盘]
  D --> E{用户采纳?}
  E -- 否 --> F[保存为报告]
  E -- 是 --> G[生成新内容批次草稿]
  G --> H[选择源片段/改标题/换平台]
```

## 4. 线索转化

1. 用户创建 CTA，选择短链、UTM 或表单。
2. 在内容批次级别绑定 CTA。
3. 生成平台版本时自动写入对应链接或发布说明。
4. 线索进入 SourceFlow 轻量列表。
5. 用户按平台、内容、CTA、时间筛选并导出。

## 5. 平台降级矩阵

| 场景 | 自动能力 | 降级体验 |
| --- | --- | --- |
| 平台支持发布和数据 | 自动排期、发布、回传 | 无 |
| 平台只支持数据 | 内容排期提醒、复制文案 | 一键复制媒体/文案 |
| 平台无稳定授权 | 不在后台宣称自动发布 | 下载 ZIP 发布包和发布清单 |
| 授权过期 | 暂停受影响排期 | 重新授权后自动恢复队列 |
| 发布失败 | 平台错误码和重试 | 连续失败后导出发布包 |
