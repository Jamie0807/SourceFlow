# SourceFlow 桌面端 / Web 端 PRD

桌面端和 Web 端使用同一套大屏信息架构。桌面客户端可以提供本地文件拖拽、后台转码和通知能力；Web 端使用浏览器上传和网页通知。页面、组件、快捷键和权限保持一致。

## 1. 设计目标

- 让用户同时看到内容源、内容批次、平台版本和发布状态。
- 让批量生产比逐条编辑更高效。
- 让 AI 建议可解释、可修改、可撤销。
- 让数据复盘直接连接到下一次生成，而不是停在报表页。

## 2. 布局规范

### 2.1 推荐尺寸

- 设计基准：1440 × 900。
- 最小支持：1280 × 720。
- 1200—1279：收窄右侧面板，保留核心操作。
- <1200：提示使用移动端或允许横向滚动，不在大屏端强行压缩三栏编辑器。

### 2.2 全局布局

```text
│ 工作台       │                                                │
```


## 3. 页面规格

### DW-01 工作台首页

目标：让用户在 10 秒内知道今天要做什么。

模块：

- 今日待办：待审核、待发布、失败重试、授权过期。
- 最近内容批次：显示源内容、资产数、状态、表现。
- 快速入口：上传内容、粘贴链接、从复盘生成、创建空白批次。
- 本周数据：已发布、总曝光、互动率、线索。
- AI 提醒：建议复用的高表现内容、未使用的候选片段。

空状态：用一个示例批次演示“上传—生成—发布”的三步流程，按钮文案为“上传第一条内容”。

### DW-02 内容库

支持按源内容/内容批次/资产/平台/标签/负责人筛选。左侧筛选，中央列表或卡片，右侧预览。

批量操作：归档、打标签、提交审核、排期、导出、删除。

### DW-03 AI 内容工作台

入口可来自上传后的 Source，也可来自“从复盘生成”。

步骤条：

1. 选择来源。
2. 选择要生成的平台和内容类型。
3. 配置语气、受众、数量、CTA。
4. 预估用量并开始生成。
5. 查看任务队列。

生成中允许离开页面；右上角任务中心显示进度。生成结果以卡片网格呈现，可多选进入批量编辑。

### DW-04 内容编辑器

左侧显示源内容时间线和已选片段；中间是当前平台预览；右侧是 AI 助手、规格检查和品牌规则。

必须支持：

- 平台版本 Tab 切换。
- “基于此版本重写/缩短/更口语/更专业”。
- 逐句引用源内容。
- 一键替换标题、CTA、标签。
- 版本对比和恢复。
- 发送审核、批准、退回。

### DW-05 发布日历

支持周视图为默认，月视图用于规划，列表视图用于批量操作。

交互：

- 拖拽卡片改变发布时间。
- 拖拽跨平台复制资产时提示“复制为新版本”或“保持同一文案”。
- 冲突时不阻止操作，但显示明确警告。
- 平台 B/C 级能力显示复制/导出图标。

### DW-06 数据复盘

页面结构：

1. 时间范围、品牌、平台、内容类型筛选。
2. 指标总览卡片。
3. 内容批次表现排行。
4. 主题/标题/开头/发布时间分解。
5. AI 复盘结论。
6. “采纳建议并生成下一批”按钮。

每个 AI 结论显示：依据指标、样本数量、时间范围、置信度和查看原始内容入口。

### DW-07 线索

显示线索列表、来源内容、平台、CTA、时间和标签。默认隐藏敏感字段，导出需要权限。

### DW-08 设置与账单

分为：工作区、品牌、平台账号、成员与权限、模板、通知、账单与用量、数据与删除。

## 4. 关键交互规则

- 所有生成任务可取消；已经产生的资产不因取消而删除。
- 批量编辑失败时保留成功项并标记失败项。
- 离开未保存编辑器时自动保存草稿并提示保存时间。
- 删除源内容前显示受影响的资产和批次数量。
- 发布前的风险提醒必须支持逐条忽略并记录操作者。
- 任何不可逆动作使用二次确认；普通编辑不弹确认。

## 5. 视觉与组件建议

- 主色：深青/蓝绿，用于“进行中”和主 CTA；警示用橙色，错误用红色，成功用绿色。
- 背景以浅灰为主，工作区卡片使用白色，避免视觉噪声。
- 资产状态使用图标 + 文本 + 颜色三重表达。
- 文字编辑器支持 Markdown 快捷语法，但默认保持所见即所得。
- 表格、卡片、时间线、抽屉、弹窗、Toast、步骤条、媒体播放器为第一批组件。

## 6. 键盘与效率

- `N`：新建内容批次。
- `U`：上传内容。
- `G`：打开 AI 生成。
- `C`：打开内容库。
- `K`：打开命令菜单。
- `Cmd/Ctrl + Enter`：提交审核或保存。
- `Cmd/Ctrl + Shift + Enter`：批准。
- `Esc`：关闭抽屉或取消当前 AI 操作。

## 7. 大屏端验收

- 1440 × 900 下三栏编辑器可同时显示且主要按钮不折叠。
- 1280 × 720 下右侧面板可以折叠，编辑和发布仍可完成。
- 鼠标、键盘和拖拽三种方式都可以完成排期。
- 生成、审核、发布和复盘之间始终保留内容批次上下文。
