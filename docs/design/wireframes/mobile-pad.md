## 4. 移动端原则

- 底部固定主操作，不把关键操作藏在长按或 hover 中。
- 列表卡片只显示决策所需信息，详情页再展开完整内容。
- 大屏上的三栏信息在小屏拆成“列表 → 详情 → 操作抽屉”。
- 复杂图表转为指标卡和可横向滑动的简图。
